# Momentos Spa Habana - Modern Web Experience

Sitio web oficial y moderno de **Momentos Spa** (Miramar, Playa, La Habana), rediseñado con arquitectura CRO de bienestar de alta gama, catálogo interactivo con páginas dedicadas para cada uno de los 27 tratamientos, panel de administración con subida de imágenes desde el dispositivo, integración en tiempo real con la hora de Cuba y conexión directa a WhatsApp (+53 59710688) y Google Maps.

## 🌿 Características Principales
- **Arquitectura Visual CRO:** Estilo Behance Wellness Redesign, paleta cálida caoba y crema (`#5A2D1F` / `#3C1318` / `#FAF7F2`).
- **Páginas Propias para cada Servicio:** 27 rituales con galerías de fotos auténticas, desglose paso a paso, beneficios y recomendaciones.
- **Subida de Fotos desde Dispositivo:** En el Dashboard de Administración se pueden subir fotos directamente desde el móvil o PC, cambiar la foto principal y gestionar la galería.
- **Horario Dinámico en Vivo (Cuba Time):** Indicador en tiempo real según el huso de La Habana (`America/Havana`) de si el spa está abierto o cerrado.
- **Reserva Interactiva:** Calendario de Miércoles a Domingo (10am a 7pm) con despacho formateado automático a WhatsApp (+53 59710688).
- **Dashboard Administrativo:** Gestión de clientes registrados, citas y catálogo de precios.

## 📍 Ubicación
Calle 44 #111 entre 3ra y 1ra A, Miramar, Playa, La Habana, Cuba.
